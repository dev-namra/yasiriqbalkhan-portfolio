# Yasir I. Khan: portfolio (React + Tailwind)

    npm install
    npm run dev      # local preview
    npm run build    # output in dist/

Deploy: push to `main`, then in the GitHub repo go to Settings > Pages > Source: "GitHub Actions".
Images, fonts and the video currently load from the original Framer CDN; download them into `public/` and update `img()` in `src/App.jsx` to make the repo self-contained.
